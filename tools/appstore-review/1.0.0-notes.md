2) PURPOSE AND TARGET AUDIENCE
Pickup codes arrive as SMS and get buried in Messages. Allude collects them into one list, so the user does not scroll through threads at the locker. Audience: Chinese online shoppers who receive several delivery SMS per week. Value: one offline list of pending codes, one-tap "picked up", home/lock-screen widgets and a Live Activity showing the code, plus simple pickup stats.

3) SETUP AND MAIN FEATURES
No account, no login, no credentials required. First launch: terms → onboarding → Pending list.
Add a code via "+" (top right): (a) paste an SMS — sample at the end of this note; (b) photo or screenshot — on-device Apple Vision OCR, nothing leaves the device; (c) optional Apple Shortcut (link inside Settings › 快捷指令) hands codes over — the app never reads Messages itself.
Tap the circle on a card → the record moves to the Picked tab. Long-press a card for copy / share / detail. Settings › 外观与个性化 controls appearance and the 17 app icons.
Allude Pro: the banner at the top of Settings opens the paywall (annual $1.99, lifetime $9.99; prices come from StoreKit). Pro unlocks unlimited records, all widget sizes and Live Activity. The free tier is fully usable.
USER-GENERATED CONTENT: no public feed, comments or user profiles, so no reporting or blocking mechanism applies. The only user-authored text is the SMS the user pastes for their own record, stored on device only.

4) EXTERNAL SERVICES, TOOLS AND PLATFORMS
- No third-party SDKs: no analytics, no advertising, no crash reporting, no developer-owned backend. The developer receives no user data.
- Apple StoreKit 2 — in-app purchases.
- Apple iCloud Documents — optional, Pro only, off by default; syncs the user's own records between the user's own devices in their private container.
- Optional third-party AI providers (DeepSeek, Volcengine Ark, Alibaba Qwen, Moonshot Kimi). Off by default. The user pastes their own API key (kept in Keychain) and the app calls that provider's official endpoint directly from the device — no proxy, no server of ours. Used only to improve parsing of an SMS the user chooses to scan.
- Apple Shortcuts — optional automation entry, distributed as iCloud shortcut links.

5) REGIONAL DIFFERENCES
None. Every feature is identical in all storefronts, with no region-locked content. The UI is localized in Simplified and Traditional Chinese only.

6) REGULATED INDUSTRY / THIRD-PARTY MATERIAL
Not a regulated industry; no licensed content. Courier brand names and logos (e.g. 韵达 / 申通 / 极兔) appear solely so the user can recognize which carrier a code they already received belongs to — descriptive use identifying the source of the user's own SMS, with no partnership or endorsement implied. ## 二、录屏怎么录（只能真机做）

**设备**：任意支持的 iPhone，系统升到最新正式版（当前 iOS 27.x）。模拟器录屏**不算**，苹果明确要求 physical device。

**录制方式**：控制中心 → 屏幕录制（系统录屏即可，不需要拿另一台手机拍）。

**开头必须是**：停止在**主屏幕**，手指**点 App 图标**启动 —— 苹果要看"从启动开始"。

**按顺序走一遍（约 2 分钟）**：

1. 主屏点 Allude 图标启动
2. 法律条款页 → 同意
3. 引导页 → 走完
4. 待取列表（有卡片）
5. `+` → 粘贴解析添加 → 粘一条样例短信 → 解析出卡片 → 保存
6. 列表里点某张卡片的圆圈 → 卡片移到已取
7. 切到「已取」标签 → 点「分组与排序」切一次分组 → 点「选择」勾两条 → 「分享 2」→ 分享面板出现 → 点「完成」
8. 切「统计」标签，停 3 秒
9. 切「设置」→ 进「外观与个性化」→ 点「自定义 App 图标」，停在图标网格
10. 返回设置 → 点顶部 Allude Pro 横幅 → **订阅页停 5 秒**，让两档价格和「恢复购买」都看清 → 返回（**不要真的付款**）

**交付方式**（三选一，给我一个能公开访问的链接）：
- iCloud 相册/文件共享链接（最省事，苹果审核员可下载）
- YouTube「不公开」链接
- 微信传给我？不行，我需要 URL。
