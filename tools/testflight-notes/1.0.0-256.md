1.0.0 (256) 测试内容

本版解决「小组件里的灰色占位行被误认为还有快递没显示出来」，并修好「设置里的开关关了不记住」。

变化
1. 设置 › 桌面小组件 › 空位：新增「显示占位符」开关，默认开（与旧版行为一致）。
2. 修复「显示内容」的开关关了不记住：关掉「显示驿站」后退出再进来，现在就保持关掉。
3. 关掉后，一页里没填满的位置直接留白，不再画灰色占位骨架。
4. 页面顶部「效果预览」只放 2 条示例，第 3 行就是空位，改哪个开关立刻能看出差别。
5. 「空位」里的开关改名为「显示占位符」。
6. 「液态玻璃」开关从「外观」页移到「外观与个性化」页（iOS 26 及以上才显示）。
7. 「显示「统计」」下方补一句说明：关掉后底部菜单栏只剩 待取 / 已取 / 设置。
8. 「自定义 App 图标」：这一行改名并去掉右侧当前图标名，点进去再选。

测试重点
1. 设置 › 桌面小组件：找到「空位」这一块，确认开关默认为开。
2. 关掉后回桌面看小组件（小 / 中 / 大）：没填满的那一页不应再出现灰色条。
3. 再打开开关，确认灰色条回来；退出页面再进来，开关状态要跟刚才一致。
4. 把「显示驿站」关掉，退出页面再进来：仍然关着（这一版重点修的）。
5. 若开了 iCloud 同步：另一台设备是否也变成同样的设置（同一 Apple ID）。
