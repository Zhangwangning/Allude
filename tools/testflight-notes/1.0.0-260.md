1.0.0 (260) 测试内容

本版把「扩展」（第三方大模型）真正露出来，并把四家的官方图标接上。

变化
1. 设置 › Apple 智能与扩展：现在先进总览页，里面分「Apple 智能」和「扩展」两个入口（之前只能进 Apple 智能，扩展入口被挡住了）。
2. 扩展列表：DeepSeek / 豆包 / 千问 / Kimi 四家，各用官方图标，右侧显示「已接入 / 未接入」。
3. 列表页「关于数据」改成中性底色，并写清：App 本身不联网，只有你主动开启并触发增强时，那条短信原文才由本机直连你选的服务商，内容不经过开发者。
4. 设置 › 桌面小组件 › 空位：开关文案改为「显示占位符」，并修好「关掉不记住」的问题（显示驿站、占位符都会记住）。

测试重点
1. 设置 › Apple 智能与扩展 → 能进总览，再进「扩展」看到四家，图标是否正常。
2. 任选一家填 API Key（可先填个假的）→ 保存 → 返回列表看是否变「已接入」；关掉开关再回来，状态是否保持。
3. 桌面小组件 > 空位：关掉「显示占位符」，回桌面看小/中/大三尺寸是否都不再画灰条。
4. 显示内容里关掉「显示驿站」→ 退出该页再进，开关是否仍是关的。
