本版重点：图标体系升级 + iPad 底部标签栏。

1. 新增 4 套 App 图标：霓虹 A、折纸 A、牛皮纸、包裹 —— 现在共 12 套可选。
2. 图标设置页**不再在图标下面显示名称**，只留图形（名称进无障碍标签）。
3. 所有图标（默认 + 12 套备用）都迁到资产目录，并补齐 **深色 / 着色（Dark / Tinted）** 外观，iOS 18 起会跟随系统自动切换；iOS 17 仍用普通外观。
4. iPad 上标签栏改回**底部**（iPadOS 18+ 原生会把标签栏放顶部，这版改成自绘底部胶囊栏），iPhone / Duo 不变。

测试重点：
• 设置 › App 图标：12 个格子都没有名字，切换任意一套后回桌面确认图标变了。
• 系统切到深色（设置 › 显示与亮度 › 深色），回桌面看图标是否变成深色版；iOS 18 及以上才有深色/着色图标，17 上不生效是正常的。
• iPad：底部能看到「待取 / 已取 / 统计 / 设置」胶囊栏，点四个标签都能切；顶部不再有标签栏。
• iPhone：原生底部标签栏保持原样，进设置二级页仍会收起。
