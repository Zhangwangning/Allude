这一版加了四套新图标，都在设置里的自定义 App 图标里。第一套是黑底配一道白色微笑弧，底下写着 Codelumi；第二套是蓝底白框，同样的微笑和名字；第三套是白底上一个蓝色玻璃立方体，两面分别写着 CODE 和 LUMI；第四套是黑底四块白色方格，中间竖着一根蓝色柱子。加上原来的十一套，现在一共十五套可选。

换的方法和以前一样：设置、外观与个性化、自定义 App 图标，点哪一格就换哪一格，桌面、App 资源库、多任务和通知里的图标会一起变。新图标用的是你给的原图，没有做任何裁切或修改，所以四周保留了一点留白，在小尺寸图标上看会比较明显，这是有意为之。

另外把 App 里的更新说明整段重写了一遍。以前版本历史里每个版本都堆着十几条，全是页头多少点、侧栏多宽、某个开关反复调了哪几次这种内部细节，读起来像开发日志。现在一个版本只留几句话，写的都是你能直接感觉到的东西：哪里变好了、多了什么、修了哪个问题。1.0.0 那一版原来有三十四条，现在剩七条。内测记录也从五十八个构建精简到十五个，中间那些已经下线的功能、纯粹调布局的反复过程都去掉了。

测试建议这么走。先打开设置换一换新图标，四套都点一遍，看看桌面和通知里的图标是否跟着变，再切回你原来用的那个。切完回主屏幕确认图标显示正常，没有出现灰块或者空白格。

顺带看一眼版本历史页，路径是设置、关于、版本。这一页现在应该清爽很多，每个版本几句话就能读完，1.0.0 卡片底部的内测记录展开后是十五个构建，收起时显示「15 个构建」。如果哪句话读着别扭、或者发现还有残留的内部说法，麻烦记下来告诉我，我再改。

覆盖安装的老规矩照旧，找一台原本装着旧版本的设备直接覆盖装上去，确认取件记录、已取、驿站组、通知开关、iCloud 同步状态都还在。这一步每次都别跳。

已知限制还是那两条。iPhone Duo 内屏横屏时，系统会把标签栏和右上角的分享按钮排在窗口最右边那条窄带子里，那条带子收不到触摸，看着能点其实点不动，属于该姿态的环境限制。模拟器里看不到真实的灵动岛，也是环境限制，和 App 本身无关。
