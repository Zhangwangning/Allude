1.0.0 (261) 测试内容

本版把「带自己的模型」这件事做完整：拿 Key 有直达入口、粘贴不用手打、能当场测通不通，还允许用自定义（OpenAI 兼容）接口。

变化
1. 扩展 › 任一家详情页：新增「从剪贴板粘贴」、每家开放平台的「创建 Key」直达链接。
2. 新增「测试连接」：当场发一次最小请求，直接告诉你 Key 无效 / 404 模型名不对 / 429 额度用尽 / 连不上。
3. 新增「自定义接口地址」（默认关）：可填自建网关或聚合服务的 OpenAI 兼容端点，留空则用官方地址。
4. 文案写明：开放平台 API Key 与 App 内会员订阅不是同一套额度。

测试重点
1. 进任一家 → 点「去…创建 Key」能否跳到对应控制台。
2. 复制一个 Key → 「从剪贴板粘贴」→ 保存 → 「测试连接」，看提示是否准确（故意填错一个字符应报 401）。
3. 打开「自定义接口地址」填一个错误地址，测试连接应报连不上/404；关掉后回落官方地址。
4. 扩展列表回到「已接入/未接入」状态是否与保存结果一致。
