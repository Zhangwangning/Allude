「扩展」页收口：模型用列表选，文案只说数据隐私，不提扣费。

变化
1. 模型改成下拉列表（DeepSeek 2 / 豆包 4 / 千问 4 / Kimi 5），已存的豆包 ep- 接入点会保留在第一项。
2. 保留：从剪贴板粘贴、开放平台创建 Key 的直达链接、测试连接（401/404/429 分别给结论）。
3. 去掉所有关于扣费/额度/订阅的说明；页面只讲数据边界：不联网、不经开发者、不记录、Key 只在本机。

测试重点
1. 任选一家 → 模型弹出列表，模型列表就地展开在字段下方，勾选在模型名右侧；选中后显示正确，保存后退出再进仍在。
2. 填真 Key → 测试连接「连接正常」；改错一个字符应报 401。
3. 页面里不应出现「扣费 / 额度 / 订阅」相关字样。
4. 扩展列表的「已接入 / 未接入」与保存结果一致。
5. 模型下拉沿用「通知 › 等待时长」那套自绘菜单：从该行下方弹出气泡、勾选在名称最右侧（Apple 蓝），点选后收起。

6. 第三方模型增强的抗抖动：请求 8 秒 / 整条 12 秒超时，最多 2 条并发、每条最多重试一次；
   失败就放弃，**入库与界面完全不受影响**（取件码永远用正则结果）。
