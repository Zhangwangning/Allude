# 1.0.0 (244) 测试内容

本版重点：**iPad 原生支持** + **iCloud 同步（可选）** + 解析修正 + 同步页简化。

## 这版改了什么

1. **iPad 原生支持**：应用从「仅 iPhone」改为 Universal。iPad 上列表与详情自动左右两栏、设置自动左侧分组右侧内容，不再是一个居中的 iPhone 窗口；支持四个方向旋转。
2. **iCloud 同步页重做**：只剩 开关 → 说明入口 → 四行状态（网络 / iCloud / 同步状态 / 最近同步）→ 立即同步。
3. **同步有反馈**：点「立即同步」后，同步状态行显示「正在同步…」+ 转圈，完成后变「同步成功」、最近同步变「刚刚」；同步在后台线程跑，界面不会卡。
4. **不做同步通知**：失败只在页面里显示原因，不弹通知、不打扰。
5. **新短信格式**：「【申通快递】您的申咚咚按需派送运单9005，已放到…(兔喜快递超市)」这类没有取件码的短信，能识别成「运单尾号 9005」、申通快递、地址去掉括号里的驿站名。
6. **地址括号修正**：括号里是驿站品牌名时不再拼到地址前面。

## 请这样测

1. **iPad**：装到 iPad，看列表是否左右两栏、设置是否左侧分组右侧内容；旋转屏幕看布局是否跟着变。
2. **iCloud 同步（重点，需要两台设备，登录同一 Apple ID）**：两台各打开一次 App → 设置 › iCloud 同步 打开开关 → A 机新增/标记已取/删除一条 → B 机冷启动打开 App 看是否一致；被删的那条不应复活。
3. **同步动画**：点「立即同步」，看状态行是否出现「正在同步…」和转圈，结束后变「同步成功」。
4. **解析**：用「添加 › 粘贴短信」粘上面那条申通短信，看是否为尾号 9005 / 申通快递 / 地址不含括号内容。
5. **Pro**：沙盒购买（不扣费），确认大尺寸小组件与实时活动解锁。

## 说明

- 不联网、不需要注册；关闭 iCloud 同步时数据只在本机。
- 卸载 App 会删掉本机数据，iCloud 里那份不受影响。
- 反馈直接走 TestFlight。
