1.0.0 (263) 测试内容

「扩展」里的模型名改成**列表选择**，不用再手打；接口地址固定官方端点，不可改。

变化
1. 扩展 › 任一家详情页 →「模型」变成下拉列表（DeepSeek 2 个、豆包 4 个、千问 4 个、Kimi 5 个）。
2. 之前存过的模型（例如豆包的 ep-xxx 接入点 ID）会保留在列表第一项，不会被丢掉。
3. 保留：从剪贴板粘贴、去开放平台创建 Key 的直达链接、测试连接（401/404/429 分别给结论）。

测试重点
1. 任选一家 → 点「模型」能弹出列表、选中后显示是否正确。
2. 保存 → 退出再进，选中的模型是否还在。
3. 填真 Key → 测试连接应返回「连接正常」；把 Key 改错一个字符应报 401。
4. 豆包如果之前填过 ep- 开头的接入点，确认它还在列表里且能继续用。
