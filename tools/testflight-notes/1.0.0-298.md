1.0.0 (298) 测试内容

iPad 全部改用 Apple 原生组件（iOS 26 液态玻璃），不做自绘、不做侧边栏：
1. 标签栏是**系统原生**的（iOS 26 液态玻璃观感，位置由系统决定 —— iPad 上在顶部），滚动收起/回弹等行为随系统。
2. 四个标签页单列、无侧边栏、无分栏；标题是系统 large title。
3. 自绘的底部胶囊、UI 兜底材质、兼容开关全部移除。
4. 设置 → Apple 智能与扩展 → 扩展 / Apple 智能：单栈 push。

请验：顶部标签栏是不是你要的液态玻璃；设置里「Apple 智能与扩展 → 扩展 → DeepSeek」能否进二级页。
