# 1.0.0 (243) 测试内容

本版重点：**iPad 原生支持** + **iCloud 同步** + 解析修正。

## 这版改了什么

1. **iPad 原生支持**：应用从「仅 iPhone」改为 Universal。iPad 上列表与详情自动两栏、设置自动分栏，不再是一个居中的 iPhone 窗口。
2. **iCloud 同步页改成状态面板**：可以看到网络、iCloud、同步状态、最近同步时间，并有一个「立即同步」。开关行只留标题，说明统一放在页面底部。
3. **去掉同步异常通知开关**：同步失败不弹通知，只在页面里显示原因。
4. **新短信格式**：「【申通快递】您的申咚咚按需派送运单9005，已放到…(兔喜快递超市)」这类没有取件码的短信，现在能识别成「运单尾号 9005」、快递公司「申通快递」、地址去掉括号里的驿站名。
5. **地址括号修正**：括号里是驿站品牌名（兔喜快递超市等）时不再拼到地址前面。

## 请这样测

1. **iPad**：装到 iPad，看列表是不是左右两栏（左边列表、右边详情），设置是不是左边分组、右边内容；旋转屏幕看布局是否跟着变。
2. **iCloud 同步（重点，需要两台设备）**：两台设备登录同一个 Apple ID → 各打开一次 App → 设置 › iCloud 同步 打开开关 → A 机新增/标记已取/删除一条 → B 机冷启动打开 App，看是否一致；被删的那条不应复活。
3. **同步页面**：看「网络 / iCloud / 同步状态 / 最近同步」四行是否有值；点「立即同步」后「最近同步」应更新为「刚刚」。
4. **解析**：把上面那条申通短信通过「添加 › 粘贴短信」走一遍，看是不是尾号 9005、快递公司申通、地址不含括号内容。
5. **Pro**：沙盒内购买（不扣费），确认大尺寸小组件与实时活动解锁。

## 说明

- 不联网、不需要注册；关闭 iCloud 同步时数据只在本机。
- 卸载 App 会删掉本机数据，iCloud 里那份不受影响。
- 反馈直接走 TestFlight。
