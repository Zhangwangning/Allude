1.0.0 (262) 测试内容

本版把「带自己的模型」做完整：拿 Key 有直达入口、粘贴不用手打、能当场测通不通。**接口地址固定为各家官方端点，不可改。**

变化
1. 扩展 › 任一家详情页：新增「从剪贴板粘贴」、每家开放平台的「创建 Key」直达链接。
2. 新增「测试连接」：当场发一次最小请求，直接告诉你 Key 无效（401）/ 模型名不对（404）/ 额度用尽（429）/ 连不上。
3. 文案写明：开放平台 API Key 与 App 内会员订阅不是同一套额度；地址内置不可改。

测试重点
1. 进任一家 → 点「去…创建 Key」能否跳到对应控制台。
2. 复制一个 Key → 「从剪贴板粘贴」→ 保存 → 「测试连接」；故意改错一个字符应报 401。
3. 模型名故意写错，测试连接应报 404。
4. 保存后返回列表，「已接入 / 未接入」是否与保存结果一致。
