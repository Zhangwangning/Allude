1.0.0 (250) 测试内容

本版重点：设置里新增「Apple 智能与扩展」，扩展支持自备 API Key 接入第三方模型；iPad 使用系统原生标签栏；若干解析与同步修复。

主要变化
1. 设置 › Apple 智能与扩展：两个独立入口 —— 端侧「Apple 智能」（原检测页）与「扩展」（DeepSeek / 豆包 / 千问）。
2. 扩展为可选、默认关闭：开启并填入自己的 API Key 后，仅对**地址为空或位置信息缺失**的短信，由本机直连服务商补充字段。
3. 安全边界：Key 只存本机 Keychain；短信原文由设备直连服务商官方接口，不经过开发者服务器；App 不记录短信内容，关闭开关即完全不发请求。
4. iPad 改用系统原生 sidebarAdaptable 标签栏（顶部，可折叠为侧栏），不再自绘底部栏。
5. 外观与个性化新增「显示统计」开关，关掉后底部只剩 待取 / 已取 / 设置。
6. 实时活动的品牌图标改为静态资源渲染，修 iPad 锁屏卡片图标变灰块。
7. 解析：识别「按需派送运单9005」这类没有取件码的短信；括号里的驿站名不再被前置进地址。
8. iCloud 同步（可选、默认关闭）保持上一版行为，本版只补了说明与状态面板细节。

测试重点
1. 设置 › Apple 智能与扩展 › 扩展：三家分别填 Key、开启、保存；关掉开关后确认不再发起请求（可断网对比）。
2. 隐私政策 / 使用条款里新增的第三方模型条款文案是否通顺、与 App 内行为一致。
3. iPad 顶部标签栏 + 折叠为侧栏；iPhone 底部栏是否仍正常。
4. 外观与个性化「显示统计」开关切换后，底部按钮即时变化，无需重启。
5. 申通那条「按需派送运单9005」短信的解析结果（尾号 9005、申通快递、台州天台何方赵兔喜生活店）。
6. 若已开 iCloud 同步：两台设备同 Apple ID 下新增/删除记录的双向同步。
