1.0.0 (321) 测试内容

新增
1. 取件码排序改成「按真实大小」：以前是一位一位比字符，所以 8-4-1005 会排到 8-4-999 前面、纯数字 90050 会排到 110226 后面。现在：
   · 纯数字按数值比（110226 在 90050 之后）；
   · 带连接符的按段比（8-4-999 → 8-4-1005 → 8-4-3020）；
   · 带字母的先比字母段、再比后面的数字（YT169555 → YT169558）；
   · 前导零不影响（090050 与 90050 视为同值，按原文稳定排列）。
2. 驿站创建时就能加位置：添加驿站 / 新建驿站组时多了一行「位置（可选）」，点进去就是当前所在位置，想换就点地图别处，保存后随驿站一起生效。不用再「先保存、再回来设位置」。
3. 驿站组编辑页的图标区重做：原来是一排文字分段控件 + 一个只有名字的下拉菜单，选之前完全看不出图标长什么样。现在是三格带缩略图的来源选择（名称首字 / 自定义图片 / 继承成员），每一格直接画出「选它之后组会长什么样」；继承成员改成可点选的图标横条，点一下即继承。
4. 驿站组的位置区：标题由「位置与到达提醒」改回「位置」，这里只管定位；主操作是「在地图上选择位置」，成员位置沿用改成下面的图标横条，随时可以改回自己选点。

改进
5. 定位页面打开就自动取一次当前位置并落点（原来要先按一下「用当前位置」）。地图右下角原来的整条按钮收成右上角一个圆形定位钮，也不压地图的法律信息水印。
6. 设置 › 驿站管理 ›「驿站内排序」下面的说明文字删掉了，只留标题和排序方式。

重点验证
· 驿站内排序切到「取件码 · 0→9、A→Z」：同一个驿站里 8-4-999 应排在 8-4-1005 前面、110226 应排在 90050 后面、YT169555 应排在 YT169558 前面。
· 添加驿站：点「添加」→ 填名字 → 点「位置（可选）」→ 应是当前所在位置 → 换一个点 → 保存 → 回到驿站管理，该格子的右上角应出现定位角标。
· 新建驿站组：不先保存直接点「在地图上选择位置」，选完保存后组应带着这个位置。
· 驿站组编辑页图标：三格应各自显示真实缩略图；选「继承成员」后组图标立刻变成该成员的图标。
· 内置驿站（比如菜鸟驿站）点图标进入定位页，位置仍应正常读写。

说明
· 位置只存在本机，用于判断你有没有到店，不上传、不记录轨迹；到达提醒需要「始终允许」定位，只在你主动开启时才申请。
· 桌面小组件的组名与取件码样式需要真机验证（模拟器包没有 App Group，跨进程读不到）。
