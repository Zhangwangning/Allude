## 本版改了什么

- **首启同意页换材质**：iOS 26 及以上用系统液态玻璃，iOS 17–25 用系统毛玻璃，条款卡、确认弹窗与底部操作条统一成一套。
- **修一处解析错误**：短信正文只写「圆通快递」时，平台曾被纠成「中通快递」（圆→中、快→速 编辑距离相同、按词表顺序先撞上中通）。现在同距离时优先选「原文里出现过本品牌关键词」的那条，结果正确显示为「圆通速递」。
- **iPhone Duo 标签栏回到系统原生排布**：内屏横屏由系统自己排在右下竖排，App 不再接管标签栏视图。

## 测试重点

1. **首启同意页**：删掉 App 重装 → 看条款卡、勾选行、底部「同意并继续」；点「同意并继续」（不勾选时）→ 弹确认框：同意 / 查看条款 / 不同意（红色）；点蒙层或「不同意」应退回未勾选。
2. **解析**：把这条短信粘进「添加取件信息」——
   `【圆通快递】快件尾号0587的包裹已送至(北门架子上)，如有问题请与快递员联系。寄快递，选圆通，登录小程序立享优惠`
   应识别为：取件码 0587 / 平台 圆通速递 / 快递公司 圆通 / 地址 北门架子上。
3. **驿站组与排序**：驿站管理页顶部搜索、组格子上的成员数；点任一驿站 → 驿站组 › 所属 可归组或新建组；待取与已取的「按快递驿站」与桌面小组件同源（件数多在前、未标注驿站置底）。
4. **详情页手工指定**：短信只写品牌名时，编辑态「快递驿站」可选择「自动识别 / 驿站组 / 驿站」。

## 已知限制

- **iPhone Duo 内屏横屏**：系统把标签栏、导航栏「编辑」、右上「分享」都排在窗口最右侧那条 84pt 带子里，该带子里的触摸事件进不到 App，表现为「看得见点不动」。同一姿态把标签栏换成底部横排则正常可点。已确认为该姿态的限制，等真机复核。
- 模拟器里看不到真实灵动岛（环境限制，与 App 无关）。

## 需要哪些设备验证

- iPhone 直板机（iOS 17 / 18 / 26 / 27）：首启同意页材质两套分支、解析、驿站组、详情页指定。
- 桌面小组件小/中尺寸、灵动岛折叠态（真机）。
- iPhone Duo：外屏与内屏竖屏照常；内屏横屏记录一下标签栏是否可点（当前预期点不动）。
