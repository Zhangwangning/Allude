1.0.0 (251) 测试内容

本版只加了一个开关，解决「小组件里的灰色骨架行被误认为还有快递没显示出来」。

变化
1. 设置 › 桌面小组件 › 空位：新增「显示空白占位行」开关，默认开（与旧版行为一致）。
2. 关掉后，一页里没填满的位置直接留白，不再画灰色占位骨架。
3. 切换开关会立即刷新桌面小组件时间线，不需要重装或重启。

测试重点
1. 设置 › 桌面小组件：找到「空位」这一块，确认开关默认为开。
2. 关掉后回桌面看小组件（小 / 中 / 大三种尺寸都看一眼）：没填满的那一页不应再出现灰色条。
3. 再打开开关，确认灰色条回来。
4. 若开了 iCloud 同步：另一台设备是否同步到这个偏好（同一 Apple ID）。
