# 人工标注 → 重训分类器

## 1. 拿模板

```bash
/tmp/gen-template 短信语料库_v1.md > 标注模板.tsv
```

每行一条短信，前 9 列是**现有解析器的预填结果**，第 10 列是原文。

| 列 | 含义 |
|---|---|
| `预填` | `pickup` = 解析器认为是快递短信；`other` = 不是 |
| `取件码` / `运单号` / `尾号` / `快递公司` / `地址` / `货架` / `柜位` | 解析器抽出来的字段，空的表示没抓到 |
| `原文` | 短信全文 |
| `人工判定` | **要你填**：`pickup` 或 `other` |
| `人工取件码` / `人工地址` / `人工备注` | 可选：预填错了才填 |

## 2. 怎么标

- 只改**错的行**。预填对的留空，脚本会沿用预填值。
- 拿不准的留空即可，不会污染训练集。
- 用 Numbers / Excel 打开、改完**另存为 TSV**（制表符分隔），不要存成 xlsx。
- 自己的短信可以**追加**到文件末尾，序号接着排。

## 3. 重训

```bash
swiftc -O -parse-as-library -o /tmp/retrain tools/annotation/retrain.swift
/tmp/retrain 标注模板.tsv
```

输出 `CodePouch/CodePouch/Resources/CodePouchPickup.mlmodel`，
然后重新构建装机即可。脚本会打印「人工改判 N 条」与测试集指标。

## 红线

- 标注文件**只在本机**，不要提交到仓库（`.gitignore` 已排除 `标注模板.tsv`）。
- 文本里有取件码与地址，属于用户数据。
