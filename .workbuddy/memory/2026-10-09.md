## 真机打不开 + 堆叠未生效修复（2026-10-09 晚，主人反馈后）
- **真机启动闪退根因**：`navigationDestination(item:)` 闭包内执行了 `ui.detailEditing = false` —— body 求值期间修改 @Published 状态，SwiftUI fatal（"Modifying state during view update"）。模拟器冷启动不恢复导航栈所以不崩；真机 iOS 恢复上次 push 的导航状态时启动即调闭包 → 启动即闪退（「打不开」）。**铁律：navigationDestination / sheet 等内容闭包只读状态，状态修改一律放在入口手势/菜单处成对显式赋值**。
- 修复：闭包只读 `ui.detailEditing`；`row` 点按显式 `detailTicket + detailEditing=false` 成对赋值（防「菜单→编辑」的 true 残留）。
- **堆叠未生效根因**：原来按天分组（`store.grouped`），主人测试票日期各不同 → 每组一张，视觉上平铺。改为**全部车票堆一摞**（钱包式）：计数头「全部车票 · X 张 · 最近在上」，`store.tickets`（日期倒序）直接叠，`zIndex(Double(count - index))` 修正方向（原 `zIndex(Double(index))` 是反的，上层卡会被下层盖住）。`TicketDayGroup`/`grouped` 成死代码保留（无害）。
- 构建 BUILD SUCCEEDED；模拟器无环境变量正常启动进程存活（复现主人场景）、截 `wallet_normal_launch`/`wallet_stacked` 验证。真机需主人重装新包。
