# 2026-10-19 工作日志

## 待取卡（PickupCard）重设计
主人原话：移除右侧复制按钮、移除左侧「勾选已取」；品牌图标移到卡片左侧上下居中；右上角时间改成「入库时间」，按 `receivedAt` 与当前时间差，格式「已入库XX月/周/天XX小时XX分钟」（大单位有时才显示，全无则只显示分钟）；再优化布局。

### 实现
- `PickupListView.swift` → `PickupCard`：
  - 签名去掉 `isCopied` / `onToggle` / `onCopy`（卡内不再有按钮）；保留 `record` / `isDone` / `selectionState`。
  - 外层改 `HStack(alignment: .center, spacing: 12)`：左 `logoBlock`（46pt 图标，上下居中），右信息列（主名+｜平台+入库时间 → 地址+货架 → 虚线 → 取件码）。
  - `logoBlock` 复用 `CourierLogo`/`StationLogo`，多选态在图标上叠选中标记：未选=淡圈（secondary 0.5, 1.5pt），选中=accent 实圈(3pt)+右上角小勾角标（18pt 圆）。**多选指示不再是左侧独立圈**（主人选定「图标上叠选中态」）。
  - 删除旧 `selectionCircle` 与 `logoSize`。
  - 标题行去掉了原来的小图标（已挪左侧）。
- `PickupModels.swift`：新增 `PickupRecord.storageAgeText`：
  - <1min→「已入库1分钟」；<1h→分钟；<1d→小时+分钟；<7d→天+小时+分钟；<30d→周+天；≥30d→月+天。长时效不再下挂时分。
  - 卡片右上角改用 `storageAgeText`（原 `relativeTime` 保留给别处）。
- 两处调用点（列表行 744、长按菜单替身卡 880）同步去掉旧参数。

### 功能保留
`rowChrome` 本来就有：右滑「已取/删除」、左滑「复制/详情」、长按菜单。所以移除卡内勾选与复制按钮**不丢功能**。
