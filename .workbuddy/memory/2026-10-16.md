### 🔴 顺带修掉 shortcut_pickup_code 的一个隐患（重要）

**症状**：该仓首次推送被远端拒绝 —— `remote: fatal: did not receive expected object 0460a578`，

**根因两条**：
1. **本地是浅克隆（shallow clone）** —— `.git/shallow` 标记 `699766e`，历史被截断，
   父提交对象不存在 → 无法打包推送。表现为本地只看到 2 个提交，实际远端有 69 个。

**修复**：
- `git fetch --unshallow origin` 从 Gitee 补全 → 提交数 2 → **69**，
  并捞回 5 个版本标签（v7.0.0 / v7.1.0 / v7.1.3 / v7.2.1 / v7.3.0）；

⚠️ 该仓 master 仍跟踪 `origin/master`（Gitee），另两个已切到跟踪 `github/main`。
